# Track record

Every live prediction pitwall-f1 made BEFORE the race (records in `predictions/`, timestamped by their git commit), graded after it.

Log losses are averaged over driver rows (lower is better). Targets: the best open-source model found reaches 0.075 (win) and 0.191 (podium). B0 = the grid-slot baseline made at the same moment, from the same data.
